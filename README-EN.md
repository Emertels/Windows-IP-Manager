# Windows IP and Network Manager

**Version:** 1.0.0  
**Interface languages:** Brazilian Portuguese, English, Spanish, French, German, Italian, Japanese, Korean, Simplified Chinese, and Russian. The interface follows Windows UI culture; unsupported languages fall back to Brazilian Portuguese.

## What it does

Interactive menu for inspecting and managing Windows network adapters, IP settings, and MAC address operations.

## Files

Windows-IP-Manager.ps1
Session-Header.ps1
Ip-UI-Catalog.json

## Usage

1. Download or clone the complete repository.
2. Run `Windows-IP-Manager.ps1` in Windows PowerShell. It loads `Session-Header.ps1` and `Ip-UI-Catalog.json` from the same folder. Approve the UAC prompt when requested.

## Requirements

Windows 10 or Windows 11 and Windows PowerShell 5.1. Adapter and IP changes require administrator privileges; winget is not required.

## Safety and limitations

The project must not remove personal data, credentials, or content outside paths defined by the tool. Command and feature availability depends on Windows edition and version. Review CHANGELOG.md before updating.

## Development

See AGENTS-PT-BR.md and AGENTS-EN.md. The default interface language follows Windows UI culture; Brazilian Portuguese is the fallback.

## Languages, purpose, and tips

Menus, prompts, steps, confirmations, and operation messages are available in all ten languages. Keep `Ip-UI-Catalog.json` and `Session-Header.ps1` in the same folder as the main script; both are required program files.

Before setting a static IP, confirm address, mask, gateway, and DNS. Incorrect values can disconnect the PC; make changes locally or keep alternate access. The tool validates the subnet mask and every DNS address; if the adapter does not confirm the requested MAC, it attempts to restore the previous value.
